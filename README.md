## Overview

This repository contains the full experimental code, datasets, and manuscript artifacts for the paper:

> **Amharic-Centric Large Language Models: Data-Efficient Continual Pre-training and Incremental Adaptation for Low-Resource Natural Language Processing**  

We investigate data-efficient continual pre-training and incremental adaptation of Amharic language models by comparing:
- **DoRA** (Weight-Decomposed Low-Rank Adaptation)
- **LoRA** (Low-Rank Adaptation)
- **LoRA+EWC** (LoRA with Elastic Weight Consolidation)
- **Full-FT** (Full Fine-Tuning baseline)

on `roberta-base-amharic` for sequential Named Entity Recognition (NER) across three random seeds. We also introduce **EthioEnAm-Parallel**, an open-source English–Amharic parallel corpus of 19,386 verified sentence pairs.

---

## Datasets

### 1. EthioEnAm-Parallel (English–Amharic Parallel Corpus)

An open-source corpus of **19,386 verified English–Amharic sentence pairs** constructed from:
- **OPUS-100** (Tiedemann, 2012): 6,402 pairs from the standard multilingual corpus
- **KCAnchoring multi-domain reasoning benchmarks**: 12,984 pairs spanning civic, arithmetic, scientific, and biographical domains

**Data splits:**
| Split | Pairs |
|-------|-------|
| Train | 15,510 |
| Validation | 1,938 |
| Test | 1,938 |
| CL Shard 1 ($D_1$) | 5,170 |
| CL Shard 2 ($D_2$) | 5,170 |
| CL Shard 3 ($D_3$) | 5,170 |

Processed data is located in `manuscriptcpt/data/parallel_en_am/processed/`.

**Auxiliary Synthetic Bitext:** 782 explicitly tagged synthetic pairs (marked `is_synthetic: true`) generated by `code/generate_synthetic_parallel.py` for the DoRA+Synth-Aug ablation. These are strictly isolated from empirical evaluation.

### 2. Amharic NER Dataset

The NER dataset used in this study is from:
> H. M. Yohannes and T. Amagasa, "Named-entity recognition for a morphologically rich language: A case of Amharic NER," *Information*, vol. 13, no. 2, p. 94, 2022.

Please contact the original authors or access via their published repository. Place the data files in `manuscriptcpt/data/NER/` as `train.txt`, `dev.txt`, `test.txt` in CoNLL-2003 BIO format.

## Reproducing the Experiments

### Step 1: Prepare the NER Data

Obtain the Amharic NER dataset and place it in:
```
manuscriptcpt/data/NER/train.txt
manuscriptcpt/data/NER/dev.txt
manuscriptcpt/data/NER/test.txt
```

### Step 2: Build the EthioEnAm-Parallel Corpus

```bash
cd manuscriptcpt
python code/process_parallel_data.py
```

This generates the verified, deduplicated splits in `data/parallel_en_am/processed/`.

### Step 3: Preprocess the NER Data

```bash
python code/preprocess.py \
    --train_file data/NER/train.txt \
    --dev_file data/NER/dev.txt \
    --test_file data/NER/test.txt \
    --output_dir data/NER/processed/
```

### Step 4: Run Sequential Continual Learning

```bash
# Train all methods across 3 seeds
python code/train.py --method DoRA     --seeds 42 123 456
python code/train.py --method LoRA     --seeds 42 123 456
python code/train.py --method LoRA+EWC --seeds 42 123 456
python code/train.py --method Full-FT  --seeds 42 123 456
```

### Step 5: Evaluate NER Performance and CL Dynamics

```bash
python code/evaluate_ner.py --results_dir research_outputs/
```

### Step 6: Generate All 6 Publication-Quality Figures

```bash
python code/generate_publication_figures.py
```

Figures are saved to `manuscriptcpt/figures/` as both vector `.pdf` and high-resolution raster `.png`.

### Step 7: Compile the LaTeX Manuscript

```bash
cd manuscriptcpt
latexmk -pdf revised_manuscript.tex
```

## Key Experimental Results

### Sequential Monolingual NER

| Method | Final Macro-F1 | BWT | FWT | Params (%) | Cumulative Time (s) | Peak GPU (GB) |
|--------|---------------|-----|-----|------------|---------------------|---------------|
| Full-FT | 0.6616 | +0.004 | -0.007 | 100.000 | 16,114.4 | 3.253 |
| LoRA | 0.7461 | +0.0505 | +0.0237 | 1.199 | 6,634.4 | 1.846 |
| LoRA+EWC | 0.7460 | +0.0475 | +0.0231 | 1.199 | 6,526.6 | 2.009 |
| **DoRA** | **0.7458** | **+0.0513** | **+0.0325** | **1.273** | 52,426.6 | **1.683** |

*DoRA and LoRA achieve **+8.4 pp** macro-F1 over Full-FT while updating only **~1.2% of parameters** and demonstrating positive backward transfer.*

### Cross-Lingual English–Amharic Adaptation (EthioEnAm-Parallel)

| Method | BLEU | ChrF++ | METEOR | BWT (BLEU) | FWT (BLEU) | Peak GPU (GB) |
|--------|------|--------|--------|------------|------------|---------------|
| Full-FT | 22.45 | 45.18 | 34.20 | -2.14 | +0.31 | 3.782 |
| LoRA ($r=8$) | 26.15 | 50.82 | 38.90 | +0.62 | +0.85 | 2.715 |
| **DoRA ($r=8$)** | **26.82** | **51.40** | **39.65** | **+0.84** | **+0.95** | **2.410** |
| DoRA + Synth-Aug | 25.94 | 50.30 | 38.52 | +0.92 | +1.12 | 2.428 |
